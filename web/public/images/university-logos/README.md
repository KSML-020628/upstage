# University logos

Add one official logo per university. Use the university name shown on the
website as the exact filename. Transparent `.png` or `.svg` files are
recommended; `.jpg`, `.jpeg`, and `.webp` are also supported.

Examples:

- `Aoyama Gakuin University.png`
- `City University of Hong Kong.png`
- `University of Bristol.png`
- `University of the West of England(UWE Bristol).png`

The file list is detected automatically during the site build. Missing logos
are simply omitted without showing a broken image.
