# University cover photos

Add one representative campus photo per university. Use the university name
shown on the website as the exact filename and use `.jpg`, `.jpeg`, `.png`, or
`.webp`.

Examples:

- `Aoyama Gakuin University.jpg`
- `City University of Hong Kong.jpg`
- `University of Bristol.jpg`
- `University of the West of England(UWE Bristol).jpg`

The file list is detected automatically during the site build. Missing photos
keep the existing letter-based placeholder.
